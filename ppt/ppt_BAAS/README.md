# Finding answers in equipment manuals

Open **[the HTML presentation](index.html)** in a modern browser. It contains 12 slides introducing apps, chatbots, EDAV Bot as a Service, the intended equipment-manual workflow, and the pilot's evidence boundaries.

The file is self-contained: its illustration, styles, and interaction code are embedded. It works offline; external source pages open only when selected. There is no presenter view or speaker-note content.

## Controls

| Action | Control |
|---|---|
| Reveal or advance | Right arrow, Space, Page Down, or the next button |
| Previous slide | Left arrow, Page Up, or the previous button |
| Jump to a slide | Slide selector; Home/End for first/last; `index.html#7` for slide 7 |
| Read evidence and limitations | Sources button or S |
| Fullscreen | Fullscreen button or F |
| Print / save as PDF | P or browser print; all reveal content is included |
| Keyboard help | ? |

The activities are the proposed first reply on slide 2, the current-records question on slide 9, and the explanation reveal on slide 12. The planned time is about 14 minutes, subject to rehearsal.

## Rebuild

From the repository root:

```text
python ppt/ppt_BAAS/build.py
```

Edit `src/` and rebuild rather than editing the generated HTML. The build requires Python 3 and no third-party packages. The original illustration is stored in `assets/manual-search.png`; the built file embeds it unchanged.

## Evidence and scope

The content uses reviewed project records and the official EDAV integration guide, with evidence dated October 8, 2026. A source dialog accompanies every slide. The illustration is fictional. Proposed replies, the manual-search path, and the citation example describe intended behavior; they are not live demonstrations or test results.

The EDAV portal was inaccessible during preparation. The records reviewed do not establish live setup, document processing, answer quality, or user value. No equipment procedure, manual passage, credential value, private source register, or personnel information is included.
