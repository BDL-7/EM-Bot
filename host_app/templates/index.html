Connection testing

Test token acquisition on the Connect server independently of the iframe. This uses the saved Connect variables and does not display the token.

Not tested in this page session.

Test the host in this order. The browser's Network panel can show request names and status codes, but never copy, save, or share a bearer token, client secret, or RStudio-Connect-Credentials header.

  1. Confirm that Connect authentication identifies the signed-in pilot user above. A missing identity prevents token requests.
  2. Open the safe health endpoint. It should report "status": "healthy" and configuration booleans only; it never returns a token or secret. These flags confirm configuration is present, not that Entra accepts it.
  3. Return to this root page, open Developer Tools, select Network, reload the page, and inspect POST {{ browser_config.tokenEndpoint }}.

Interpret the token request safely

200
Token acquisition succeeded, possibly using a cached token. The normal iframe flow sends the token to its configured origin after the frame loads; the test button checks token acquisition only. Watch Iframe handshake for an acknowledgment.
401
Connect did not provide a usable signed-in user identity. Sign in to Connect and verify the content's access configuration before retrying.
502
The host could not obtain a usable token. This can be an Entra rejection, network failure, or application exception. Find the diagnostic reference in the response and match it to an EDAV_AUTH_DIAGNOSTIC entry in Connect runtime logs. Use the recorded stage and error code to identify the correction.
503
Required runtime configuration is incomplete. Review the Connect Vars names and values without exposing secrets.

If token acquisition returns 200 but the iframe does not acknowledge it, record the timestamp, environment, request URL, HTTP status, diagnostic reference (if present), and safe error code for EDAV. A 502 without a reference may come from Connect or a proxy; check runtime logs. Do not send tokens, client secrets, or full request headers.
